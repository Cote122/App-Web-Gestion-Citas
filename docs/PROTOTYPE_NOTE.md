# Prototipo original

`prototype.html` conserva la maqueta funcional entregada por el equipo como referencia visual y de interacción.

La implementación Angular no intenta copiar de golpe todas las pantallas del prototipo: se está migrando por historias de usuario para poder versionar, probar y revisar cada incremento.

**Importante:** el PDF académico original no se incluye en el repositorio base porque contiene nombres y correos de integrantes. Si el repositorio de GitHub será público, revisen cualquier documento antes de subirlo.
